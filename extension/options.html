ContextSwitch

Extension Settings

Local Server Port

ContextSwitch runs a local HTTP server so this extension can send pages to it. This port must match the port configured in the ContextSwitch app (open the app → click the ⚙ gear icon in the top-left). The default port is 27182.

How to use

  1. Open the ContextSwitch desktop app.
  2. Navigate to any web page you want to save.
  3. Click the ContextSwitch extension icon in your toolbar.
  4. Edit the label, choose a context, and click Add to ContextSwitch.
